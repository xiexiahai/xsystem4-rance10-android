# 《兰斯10》安卓移植版 1.0.6 更新

普通版和 cheat 版同步更新，内部版本号 **151**。

- 修复战斗 LOG 展开后多条记录重复显示同一条内容的问题。
- 修复部队编制里点击阵营页签却选中人物卡，以及列表拖到底后切换阵营可能卡住的问题。
- 修复 BGM 和音效音量串控、高速简易战斗中部分音效漏播或截断的问题。
- 「重新战斗」或败北后「再挑战」读档失败时，会显示失败环节和诊断编号。再次遇到报错，欢迎附上弹窗截图。

## 新增的桌面长按入口

- **存档迁移**可将当前档案导出为 ZIP，也可导入备份并切换档案。
- **手柄映射**可自定义确认、返回、Ctrl 快进等按键。保存后退出并重开游戏生效。

普通版和 cheat 版可同时安装，存档与手柄设置各自独立。更新时覆盖安装对应版本即可，建议先备份存档。
